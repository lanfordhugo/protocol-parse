## 三、字段类型和Scale问题

### 3.1 温度字段偏移量

**协议定义**: 温度字段偏移量-50，-50 - 200℃

**YAML现状**: 
```yaml
- {len: 1, name: 出风口温度, type: uint8, scale: 1}
```

**问题**: 未处理偏移量

**建议**: 
- 方案1: 在解析器层面统一处理偏移量
- 方案2: 在字段定义中增加 `offset: -50` 属性
